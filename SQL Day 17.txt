TCL Commands:
stands for Transaction control language
TCL commands :
-> commit
-> rollback
-> save point
-> Transaction: is a group of SQL operations. The group of SQL operations represent a single unit.
-> Transaction states : begin -> partially committed -> committed -> terminated -> abort-> fail

-> ACID properties:
Every transaction must follow acid properties
  A stands for atomicity (either all or non)
  C stands for consistency
  I stands for isolation
  D stands for durability

-> Log:
-> Log is a record.
-> The transaction should follow the different log
   1. undo log 
	stores old values, purpose is to rollback to change.
   2. redo log
	it used to read operations.
   3. binary log
	stores history of transactions.
