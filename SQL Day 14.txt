cross join: 
->select s.*,c.c_name from student s
cross join course c;
sub query: to write a query inside another query
the sub query enclosed within parenthesis
->select query condition(sub query);
i. single row sub query:
sub query returns only one row, using <,>,<=,>= etc
->select * from product where price = (select max(price) from product);
ii. multi row sub query:
sub query returns more than one row(any, all, sum, in)
iii. nested sub query:
multi level of subquery
-> select max(price) as max_price from product;
iv. co-related sub query:
---
- calculating second highest max price:
-> select max(price) from product where price < (select max(price) from product);
- calculate product name which have second highest price(nested sub query):
-> select * from product where price = (select max(price) from product where price < (select max(price) from product));
->select * from product where price < any (select price from product where category = 'Furniture');
