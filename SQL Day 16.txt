Views :
view is a virtual table or logical table.
view do not store any data, it stores select SQL query
views are created using select query
-> Advantages of  views:
security.
to avoid un necessary columns in a table.
simplify complex queries.
to maintain readability.
Types:
1. simple view:
	is created from one table, doesn't contain any complex operations like joins, aggregate functions, clauses(group by, having)		
2. complex view:  
	the view is created from one or more than one table, does contain joins, aggregate functions, clauses.
Syntax:
create view view_name select query;
simple view syntax:
create view view_name select query;
complex view syntax:
create view view_name select query;(select query using joins, clauses, aggregate functions
